# 书源可用性校验

校验流程：搜索 → 发现 → 详情 → 目录 → 正文，逐阶段探测书源是否可用。

> 本文档描述当前实现（v3.7.2）。数值以 `CheckSourceSettings` 中的常量为准。

## 配置

### 超时

- 默认值：180 秒（`DEFAULT_TIMEOUT`）。
- 设置范围：0–300 秒。
- 界面选择 0 时使用默认值。
- 内部值低于 1 秒时归一化为默认值，高于 300 秒时归一化为 300 秒。

### 并发

- 默认值：8（`DEFAULT_CONCURRENCY`）。
- 设置范围：**1–500**（`MAX_CONCURRENCY = 500`）。
- 小于 1 时归一化为 1。
- 大于 500 时归一化为 500。
- 界面、配置归一化和校验线程池使用同一上限。

### 搜索关键词

- 默认值：「我的」（`DEFAULT_KEYWORD`）。
- 用于替换搜索地址中的 `{{key}}` 和 `{key}`。
- 空白输入回退为默认值。
- 与超时、并发和校验勾选一起保存。

### 自定义可用状态码

- 默认值：`200-399`（`DEFAULT_OK_STATUS`）。
- 支持区间写法（如 `200-299`）与列举（如 `200,301,403`），可混用。

### 重置默认

「重置默认」会恢复超时 180 秒、并发 8、关键词「我的」、状态码 `200-399`，
以及全部校验阶段和类型勾选。

## 校验阶段

可选择：

1. 搜索
2. 发现
3. 详情
4. 目录
5. 正文

搜索和发现至少启用一项。关闭详情时会同时关闭目录和正文；关闭目录时会同时关闭正文。

## 书源类型

按 `bookSourceType` 判断：

- 0 或缺省：小说
- 1：音频
- 2：漫画
- 3：文件
- 4 或名称/分组提示：视频

检验对话框可选择要校验的类型。未选择的类型会跳过。

内容探测按类型进行：

- 小说：文本
- 漫画：图片地址
- 视频：播放地址
- 音频：音频地址
- 文件：下载痕迹

## 当前支持

- 常用 URL 模板。
- 相对地址。
- GET 和 POST 请求。
- 请求头和请求体配置。
- gzip 响应和 HTTP 重定向。
- 搜索、发现、详情、目录和正文返回内容探测。
- 书源 URL 身份标签不参与实际网络请求。

## 停止校验

停止操作会取消正在运行的任务和活动 HTTP 连接。已经完成的结果会保留并汇总。
下次可从断点继续校验未处理的 URL。

## 增量重验

校验结果会被记录为历史（最多保留最近 20 次）。有两种重验方式：

- **重验失败源**：右上角菜单 → 校验历史，一键重验上一轮全部失败/超时的书源
- **单条重验**：校验明细列表里每行右侧的「重验」按钮，只验这一条

单条重验的意义：想确认某一条源是否恢复时，不必跑一遍全部（万级书源要等几分钟），
也不浪费校验配额。校验进行中点击会提示先停止，避免并发启动第二个引擎。

## 结果分类

结果可能包含：

- 校验超时
- 搜索链接规则为空
- 搜索失效
- 发现失效
- 详情失效
- 目录失效
- 正文失效
- 图片失效
- 播放失效
- 音频失效
- 下载失效
- 网站失效
- js失效

结果区可用开关选择导入或保存的类型。启用“仅导出可用源”后，保存或导入时只处理本次校验结果为可用的书源。

## 当前限制

当前实现尚未包含与阅读 WebBook 完全一致的 Rhino JavaScript、CSS 和 XPath 规则执行。复杂动态脚本、登录状态、验证码和访问限制可能影响校验结果。

## 测试

JVM 测试已验证：

- 默认并发为 8。
- 0 归一化为 1。
- 100 保持为 100。
- 101 归一化为 100。
- 最大并发常量为 100。
- 空白关键词回退为「我的」。
- 书源类型判断和内容探测。
